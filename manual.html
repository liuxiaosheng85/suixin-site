1. 软件简介

随心笔记 ✦ FreeMind 是一款桌面笔记应用，采用深色主题设计，风格清新简约。软件支持富文本编辑、分类标签管理、AI 智能助手、会议录制转写等功能，适合日常笔记、会议记录、知识整理等场景。

核心特性：

  • 📝 富文本编辑 — 粗体、斜体、颜色、高亮、标题、列表、表格、代码块等
  • 📂 分类管理 — 自定义分类，灵活组织笔记
  • 🏷️ 标签系统 — 为笔记添加标签，快速筛选
  • 👁 编辑/预览模式 — 编辑时使用工具栏，阅读时预览模式无干扰
  • 🤖 AI 助手 — 按需启动，支持聊天、整理、报告、Agent 等功能
  • 🎙️ 会议录制 — 录制系统音频，AI 自动转写整理
  • 📤 导出功能 — 将笔记导出为 HTML 文件

2. 启动与界面概览

启动

双击 随心笔记.exe 启动应用。首次启动时，软件会显示「正在连接...」的加载画面，通常 1-3 秒内即可进入主界面。

界面布局

软件界面由 四部分 组成（从左到右）：

3. 笔记管理

3.1 新建笔记

点击侧边栏的 「✚ 新建笔记」 按钮，或点击编辑器空白区域的 「开始书写 ✦」 按钮。

新建笔记默认进入 编辑模式，可以直接输入标题和内容。

3.2 编辑笔记

点击笔记列表中的任意笔记卡片即可打开该笔记。已保存的笔记默认以 预览模式 打开（只读），需要点击 「✏️ 编辑」 按钮切换到编辑模式才能修改内容。

在编辑模式下：

  • 标题可直接修改
  • 内容区域可直接输入文字
  • 修改后系统会自动保存（无需手动操作）

3.3 预览模式

预览模式是阅读笔记的最佳方式：

  • 内容不可编辑，避免误操作
  • 编辑工具栏自动隐藏，界面更简洁
  • 右侧仍保留操作按钮：📌 置顶 / 📦 归档 / 📤 导出 / 🗑️ 删除
  • 标签的删除按钮（✕）隐藏，避免误删
  • 标题和分类不可修改
  • 自动保存暂停，不会因切换预览而触发保存

切换方式：

  • 点击编辑器标题行右侧的 「👁 预览」 按钮 → 进入预览模式
  • 点击 「✏️ 编辑」 按钮 → 返回编辑模式

3.4 保存笔记

自动保存：编辑模式下，每次修改内容后系统会自动保存，无需手动操作。

手动保存：如需立即保存，点击第二行工具栏右侧的 「💾 保存」 按钮。

⚠️ 注意：预览模式下不会触发自动保存，因为内容没有修改。

3.5 删除笔记

在编辑器右上角点击 「🗑️」 删除按钮，系统会弹出确认对话框，确认后删除当前笔记。

3.6 批量删除

当需要一次性删除多篇笔记时：

  1. 点击笔记列表标题栏右侧的 「📝」 按钮，进入批量管理模式
  2. 笔记卡片变为可选择状态，点击需要删除的笔记（选中后显示勾选标记）
  3. 列表顶部出现批量操作栏，显示已选数量
  4. 点击 「🗑️ 删除所选」 执行批量删除
  5. 或点击 「取消」 退出批量管理模式

3.7 置顶与归档

  • 📌 置顶：点击编辑器右上角的置顶按钮，将重要笔记固定在列表顶部。置顶的笔记可通过侧边栏「已置顶」筛选查看。
  • 📦 归档：点击归档按钮，将不再频繁使用的笔记归档。归档笔记可通过侧边栏「归档」筛选查看。
💡 提示：再次点击置顶/归档按钮可以取消操作，恢复笔记到正常状态。

3.8 导出笔记

点击编辑器右上角的 「📤」 导出按钮，将当前笔记导出为 HTML 文件。

导出位置：笔记导出文件保存在软件所在目录下的 data/exports/ 文件夹中。导出完成后，软件会自动打开该文件夹，方便查找。

💡 提示：导出按钮在编辑模式和预览模式下均可使用。

这样可以快速调整标题层级，无需删除后重新设置。

5. 分类与标签

5.1 分类管理

分类用于按主题组织笔记（如「工作」「学习」「生活」等）。

新建分类：

  1. 在侧边栏找到 「📂 分类」 区域
  2. 点击分类标题旁边的 「✚」 按钮
  3. 在弹出的对话框中输入分类名称
  4. 点击「确定」创建分类

为笔记指定分类：

  • 在编辑器标题行，点击分类下拉框选择一个分类

删除分类：

  • 将鼠标悬停在分类标签上，点击出现的 「✕」 按钮
  • 删除分类不会删除笔记，只是取消笔记的分类关联
💡 提示：软件内置了 6 个默认分类：工作、学习、生活、创意、阅读、其他。你可以根据需要增删分类。

5.2 标签管理

标签用于为笔记添加关键词标记，方便检索和筛选。

添加标签：

  1. 在编辑器信息行（标题下方），找到标签输入框
  2. 输入标签名称，按 Enter 键确认
  3. 标签会以彩色药丸样式显示

删除标签：

  • 编辑模式下：点击标签右侧的 「✕」 按钮
  • 预览模式下：标签删除按钮隐藏，防止误操作

通过标签筛选：

  • 在侧边栏 「🏷️ 标签」 区域点击标签，笔记列表会只显示带有该标签的笔记

6. 搜索笔记

在侧边栏的搜索框中输入关键词，笔记列表会实时筛选显示匹配的笔记。

搜索范围包括：笔记标题和内容。

7. 阅读辅助功能

长篇笔记阅读时，以下功能可以帮助你更高效地浏览内容：

7.1 目录导航 (TOC)

点击编辑区域右上角的 「☰」 按钮，打开目录面板。

目录面板功能：

  • 自动提取笔记中的所有标题，按层级缩进显示
  • 点击目录中的标题项，编辑器自动滚动到对应位置
  • 当前阅读位置对应的标题会高亮显示
💡 提示：目录面板适用于含有多个标题的长篇笔记。

7.2 阅读进度条

编辑区域顶部有一条细细的进度条，随着阅读滚动会实时更新，显示当前阅读进度。

7.3 回到顶部

向下滚动一段距离后，编辑区域右下角会出现 「↑」 回到顶部按钮。点击后编辑器自动滚动到顶部。

8. AI 助手

⚠️ 重要提示：AI 功能仅在用户主动点击时启用，不会在编辑或预览笔记时自动运行，不会影响软件性能。

8.1 开启 AI 面板

点击侧边栏底部的 「🤖」 按钮，右侧弹出 AI 助手面板。再次点击按钮可关闭面板。

8.2 AI 聊天

AI 聊天功能支持与 AI 助手「小墨」进行对话。

使用方法：

  1. 打开 AI 面板，默认进入「💬 聊天」标签
  2. 在顶部选择 AI 提供商和模型
  3. 选择对话范围：
    • 📄 当前笔记：AI 基于当前打开的笔记内容回答
    • 📚 全部笔记：AI 基于所有笔记内容回答
  4. 在输入框输入问题，按 Enter 或点击 ➤ 发送
  5. AI 的回复会实时流式显示

8.3 AI 整理

AI 整理功能可以优化你的笔记排版：

  1. 切换到 「📝 整理」 标签
  2. 点击 「✨ 开始整理」
  3. AI 会阅读当前笔记，优化排版、修正错别字、补充标题结构
  4. 预览结果后选择：
    • ✅ 应用：用整理后的内容替换原笔记
    • ❌ 放弃：保留原笔记不变

8.4 AI 报告

AI 报告功能可以基于笔记生成结构化报告：

  1. 切换到 「📊 报告」 标签
  2. 选择报告风格：
    • 🏢 专业：正式的商务报告风格
    • ⚡ 简洁：精炼的要点总结
    • 🎨 创意：富有创意的表达方式
  3. 点击 「📊 生成报告」
  4. 生成结果后可以选择：
    • 📝 插入笔记：将报告内容追加到当前笔记
    • 📤 导出HTML：将报告导出为 HTML 文件
    • ❌ 关闭：关闭报告结果

8.5 AI Agent

Agent 模式支持多步骤的复杂任务：

  1. 切换到 「🤖 Agent」 标签
  2. 在文本框中描述任务（例如：「帮我找出所有关于项目的笔记并整理成摘要」）
  3. 点击 「▶ 执行」
  4. Agent 会自动分解任务、逐步执行，并展示每一步的操作和结果

8.6 AI 快捷操作

编辑器底部的快捷操作栏提供一键 AI 功能：

按钮功能
✨ 摘要对当前笔记生成摘要
📝 整理对当前笔记进行排版整理
🏷️ 标签AI 推荐相关标签
🔮 扩写对当前内容进行扩写

8.7 AI 语音输入

在 AI 聊天输入框旁边，点击 「🎤」 语音输入按钮，即可通过说话输入文字（需麦克风权限）。再次点击结束语音输入。

8.8 对话历史

AI 聊天区域顶部有 「📜 历史对话」 区域：

  • 点击展开/折叠历史对话列表
  • 点击历史对话可切换到该对话
  • 点击 「✚ 新对话」 开始新的对话
  • 悬停历史对话项可看到删除按钮

8.9 AI 设置与提供商配置

点击侧边栏底部的 「⚙️」 按钮打开 AI 设置面板。

支持的 AI 提供商：

提供商说明是否需要 API Key
🦙 Ollama (本地)本地运行，免费不需要
🟢 OpenAIGPT 系列模型需要
🔵 DeepSeekDeepSeek 模型需要
🟣 SiliconFlowSiliconFlow 平台需要
⚡ GroqGroq 快速推理需要
🌐 OpenRouter多模型路由需要
🧠 智谱AIGLM 系列模型需要
💎 Google GeminiGemini 模型需要
⚙️ 自定义兼容 OpenAI API 的服务视情况

添加提供商：

  1. 在设置面板下方选择提供商类型
  2. 填写 API Key（本地 Ollama 无需填写）
  3. 填写 API Base URL（提供商会自动填入默认地址）
  4. 填写模型名称
  5. 点击 「添加 ✦」
💡 提示：推荐新手使用 Ollama 本地模型，免费且无需网络。安装 Ollama 后默认地址为 http://localhost:11434/v1。

9. 会议录制

点击侧边栏底部的 「🎙️」 按钮打开会议录制面板。

录制流程：

  1. 开始录制：点击 「⏺ 开始录制」 按钮
    • 软件会录制电脑系统音频（如在线会议的声音）
    • 录制过程中显示录制时长和状态
  2. 停止录制：点击 「■ 停止录制」 按钮
  3. 转写：停止后自动进入转写阶段，AI 将语音转换为文字
  4. 结果处理：转写完成后可以：
    • 🤖 AI 整理：让 AI 将转写内容整理成结构化会议纪要
    • 📝 保存为笔记：将转写内容直接保存为笔记
    • 🔄 新录制：开始新的录制
  5. AI 整理结果：
    • ✅ 应用到笔记：将整理结果保存为笔记
    • 📤 导出HTML：导出为 HTML 文件
⚠️ 录制前注意：
- 确保会议音频从电脑扬声器播放
- 关闭其他嘈杂应用
- 首次使用需下载语音模型（约 150MB）

10. 排序与筛选

排序： 在笔记列表标题栏右侧的下拉框中选择：

  • 最近修改：按最后修改时间排序（默认）
  • 创建时间：按创建时间排序

筛选： 通过侧边栏快速筛选笔记：

  • 📒 全部笔记：显示所有笔记
  • 📌 已置顶：只显示置顶的笔记
  • 📦 归档：只显示归档的笔记
  • 📂 分类：点击分类名，只显示该分类下的笔记
  • 🏷️ 标签：点击标签名，只显示带该标签的笔记

11. 数据存储说明

软件的所有数据存储在软件所在目录下的 data/ 文件夹中：

随心笔记/
├── 随心笔记.exe
├── data/
│   ├── notes.db          ← 笔记数据库（SQLite）
│   ├── app.log           ← 运行日志
│   ├── images/           ← 笔记中的图片
│   ├── exports/          ← 导出的 HTML 文件
│   ├── rag_index.db      ← AI 知识库索引
│   └── ai_conversations/ ← AI 对话记录

12. 常见问题

Q: 软件打开后一直显示「正在连接」

A: 这通常是由于系统环境问题导致的，可以：

  1. 等待 10-20 秒，部分系统首次启动较慢
  2. 如果出现「重新连接」按钮，点击重试
  3. 关闭软件后重新启动

Q: 笔记保存失败

A: 可能原因及解决方法：

  1. 正在切换笔记：切换笔记时会自动保存，短暂延迟属正常
  2. 网络图片：包含网络图片时保存可能稍慢，请耐心等待
  3. 如果持续保存失败，请检查 data/app.log 日志文件

Q: AI 助手无法使用

A: 请检查：

  1. 是否已配置 AI 提供商（⚙️ 设置）
  2. 如果使用 Ollama，确认 Ollama 已启动并运行
  3. 如果使用云端 API，确认 API Key 正确且网络通畅
  4. 查看 data/app.log 中的错误信息

Q: 导出的笔记在哪里？

A: 导出的 HTML 文件保存在 data/exports/ 文件夹中。点击导出按钮后，软件会自动打开该文件夹。

Q: 会议录制没有声音？

A: 请确认：

  1. 会议音频从电脑扬声器播放（非耳机独立输出）
  2. 已关闭其他嘈杂应用
  3. 首次使用需下载语音模型（约 150MB），请确保网络通畅

Q: 如何备份数据？

A: 软件每天会自动备份到 data/backups/（保留最近 7 份）。也可以手动复制整个数据目录：安装版为 %LOCALAPPDATA%\SuiXinNotes\data，便携版/源码版为软件目录下的 data/。

Q: 如何卸载？

A: 打开 Windows「设置 → 应用 → 已安装的应用」，找到「随心笔记」点击卸载。卸载不会删除你的笔记数据（保留在 %LOCALAPPDATA%\SuiXinNotes\data）；如需彻底清除，请在卸载后手动删除该目录。

13. 通讯录

侧边栏点击「通讯录」进入。支持联系人管理、组织架构浏览与笔记协作关联。

13.1 联系人管理

  • 新建/编辑：点击「＋ 新建」，右栏填写姓名、部门、职位、公司、上级、微信、生日、项目、标签、备注等。
  • 搜索：支持姓名、部门、职位、公司、项目、电话、邮箱、备注、上级、微信、生日。
  • 筛选与排序：按部门、项目、收藏筛选；按最近更新或最近互动排序。
  • 快捷操作：一键复制手机号/邮箱；收藏联系人。
  • 头像：编辑态点击「选择图片」，自动压缩到 160×160 后存入本地数据库；未设置时显示姓名首字母。

13.2 组织视图与生日

  • 头部切换到「组织」，按部门路径自动生成组织架构树，节点显示人数，点击成员查看详情。
  • 详情中的「最近互动」可点击「＋ 记录互动」，自动累计次数与上次联系时间。
  • 启动或打开通讯录时，会自动提示当天及未来 7 天内的生日（同一天只提示一次）。

13.3 导入与导出

  • 支持 vCard (.vcf) 与 CSV 导入；CSV 支持 UTF-8/GBK 自动识别。
  • 导出文件生成到 data/exports/，完成后自动打开目录。

13.4 与笔记/待办关联

  • 笔记编辑器「👥 相关人员」行可添加联系人，或点击「✨ AI 识别」按内容推荐相关人员。
  • 待办编辑弹窗「协作人」行支持同样操作，并可「从事项识别」。
  • 打开笔记时会自动在「可能相关」中给出本地匹配建议，一键添加。

14. 计划工作区

  • 待办：支持截止时间、优先级、关联笔记、协作人、完成状态与提醒。
  • 日历：月视图，显示农历与二十四节气。
  • 倒数日：记录重要日期与剩余天数。
  • 习惯：每日打卡与连续天数统计。
  • 番茄钟：专注计时，可自定义时长。

15. 数据安全与备份

  • 自动保存：编辑后约 0.6 秒自动保存；切换笔记、关闭窗口前会强制落盘，失败会显示「保存失败」。
  • 版本历史：每篇笔记保留最近版本，可在笔记菜单中查看与恢复。
  • 回收站：删除的笔记进入回收站，可恢复或彻底删除；过期内容会自动清理。
  • 自动备份：每天检查并备份到 data/backups/，默认保留 7 份，可在设置中手动备份/恢复。
  • 整库加密（可选）：设置 → 安全中开启，密码至少 8 位。退出时自动加密为 notes.vault 并删除明文；下次启动需输入密码。忘记密码无法找回。
  • 数据位置：安装版为 %LOCALAPPDATA%\SuiXinNotes\data；便携版/源码版为软件目录下的 data/。

17. 安装、升级与卸载

  1. 安装：双击 随心笔记_Setup_v1.02 安装包，按向导完成安装。默认安装到当前用户目录（%LOCALAPPDATA%\Programs\SuiXinNotes），无需管理员权限。
